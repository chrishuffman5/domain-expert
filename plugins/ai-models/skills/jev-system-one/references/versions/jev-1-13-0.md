# Jev 1.13.0 (stable)

## Identity and lifecycle

TypeSafe lists `jev-1.13.0` as the stable model ID and maps `jev-latest` to it. Its model page lists `jev-1.14.0` as the newest release available from 2026-10-14 and maps `jev-preview` to that version. Aliases can move; a response includes the versioned model ID. This catalog entry is the stable 1.13 identity, not an alias and not the preview.

## Input and context

Jev evaluates text state provided as a string, JSON object, or array. The page lists text input only. Default context limits are 64k tokens per request and 32k per question. The request limit covers state plus every question; the per-question limit covers state plus one question. The optional `TypeSafe-Danger-Zone-Long-Context: true` header raises both limits to 262k; TypeSafe warns that this mode is slower and less accurate than staying within defaults.

> Source: https://docs.typesafe.ai/models
> Source: https://docs.typesafe.ai/concepts/system-one

## Output contract and fit

Jev is TypeSafe's first System One model. It returns typed answers and probability information rather than generated prose. The documented primitives include Choice, Score, and Noul. Choice selects among caller-defined alternatives, Score evaluates against caller-defined levels or a rubric, and Noul returns a probability for a proposition. TypeSafe describes calibration across groups of predictions and explicitly cautions that it does not guarantee an individual answer.

## Price, license, and availability

The model page lists $42 per billion input tokens ($0.042 per million); output tokens are free. It documents the `/v1/systemone` endpoint and client SDKs. The inspected official pages describe a hosted commercial service and do not document downloadable weights or a weight license. Organization rate limits apply; higher limits are available on custom and enterprise plans. Exact capacity is account-specific.
