## What changed from 1.13.0

Changelog entry "Jev 1.14, October 14, 2026": improved multilingual support (no measured numbers), the Box question type (requires 1.14), images in `state`, `instructions` or `criteria`, and the 262k long-context header. Images and long context also work on 1.13. Price, default limits (64k per request, 32k per question) and text-plus-PNG/JPEG input are the same as 1.13. Choice, Score and Noul keep their shape, but recalibrate thresholds after moving versions. Some vendor example responses (quickstart, Choice/Score/Noul pages) still show `jev-1.13.0` while requesting `jev-latest`; treat those as stale examples, not evidence.

## Input, context and long context

Text state (string, JSON object or array) plus PNG/JPEG images; audio and video are unsupported. Defaults are 64k tokens per request (state plus every question) and 32k per question (state plus one question). The opt-in header `TypeSafe-Danger-Zone-Long-Context: true` raises both limits to 262k at the same per-token price; TypeSafe says it is slower and less accurate, and the blog strongly recommends keeping context short. The 262k figure appears on the models page and changelog, not in the OpenAPI spec. Routes that publish 32K (Cloudflare Workers AI, Vercel AI Gateway) or 64K (Requesty) are catalog numbers for one of the two default limits; whether they forward the long-context header is not stated.

## Box and images (beta)

Box is a fourth primitive, marked dreamer-ready and not production-ready. A `box` question takes `instructions` (what to find and in which image) and no `criteria`; the answer is `top`, `bottom`, `left`, `right` as 0..1 fractions of the image from the top-left, plus a nullable `confidence`. Box has no not-found answer and always returns a box, so pair it with a Noul and ignore the box when the Noul is low. It handles one target per question and can miss small targets in large images. Images and Box need the header `TypeSafe-Danger-Zone-Images: true` on every request containing either. Images are PNG/JPEG stills, 16 MiB per file, each side 280-1,568 px, total pixels 78,400-2,458,624, 32 MiB request body, never resized. Image tokens are billed as input and count toward context; no separate rate limits. Cloudflare's model card still describes Jev 1.13 and calls image inputs beta, not recommended for production. For selection, treat Box and images as prototype features and validate offline.

## Output contract and fit

Jev is TypeSafe's first System One model. It returns typed answers and probability information (Choice, Score, Noul, and now Box) rather than generated prose. TypeSafe describes calibration across groups of predictions and explicitly cautions that it does not guarantee an individual answer. The vendor says "danger zone" headers gate experimental features it does not recommend for production. No 1.14-specific jaggedness page exists (404 as of 2026-11-13).

## Price, license, and availability

$42 per billion input tokens ($0.042 per million); output tokens are free. Rate limits are set per organization in tokens and requests per second, shown in the developer console; excess returns 429 and custom or enterprise plans get higher limits (the earlier snapshot's specific numbers are no longer published). The inspected pages describe a hosted commercial service with no downloadable weights or weight license.
