# TabICLv2

## Identity and status

The official Soda/Inria repository identifies itself as the implementation for TabICLv2 and TabICL. It describes TabICLv2 as a tabular model for classification and regression. The repository reports v2.2.0 as the latest visible package release in the candidate snapshot; the inspected releases page did not provide a reliable release year. Do not infer one.

> Source: https://github.com/soda-inria/tabicl
> Source: https://github.com/soda-inria/tabicl/releases

## Task and scale

The repository documents supervised classification and regression, pip installation, scikit-learn-compatible estimators, and a fit/predict path using a pretrained transformer. It reports benchmark results across 300 to 100,000 training samples and up to 2,000 features. Larger datasets such as 500K samples may use CPU/disk offloading, with possible accuracy degradation. These are project-reported ranges, not universal performance guarantees.

> Source: https://github.com/soda-inria/tabicl

## License, availability, and price

The official GitHub project describes a permissive license; the official Hugging Face card lists BSD-3-Clause. The code and weights are publicly available for local Python use. The inspected model card says the checkpoint is not deployed by any Inference Provider. No public hosted inference price was found in inspected pages.

> Source: https://github.com/soda-inria/tabicl
> Source: https://github.com/soda-inria/tabicl/blob/main/LICENSE
