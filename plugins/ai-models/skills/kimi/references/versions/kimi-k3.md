## Capabilities and context

- Capabilities: text, image, and video understanding; long-horizon coding; knowledge work; reasoning.
- Context/output: 1,048,576 tokens; 2.8T total parameters and 104B activated parameters per official model card.
- Strengths: Current flagship with open weights and hosted option; Very long context and native visual input; Designed for coding, knowledge work, and reasoning.
- Limitations: 2.8T weights impose extreme self-hosting requirements; License includes meaningful scale-based conditions; review before redistributing or hosting; Technical report details and independent evaluations should be checked before benchmark claims.
