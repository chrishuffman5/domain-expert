## Capabilities and context

- Capabilities: text, image, video, and file input; visual coding; agentic tool use; reasoning effort control.
- Context/output: 1M tokens; max output 128K; 320B total parameters and 18B activated per Z.ai docs.
- Strengths: Native multimodal model for visual coding and document workflows; Sparse/linear architecture aims to reduce long-context compute; Long context and lower activated parameter count.
- Limitations: GLM-5.3-FlashX is a faster serving option; do not treat as separate weights; Official comparative cost/intelligence claims are provider-authored; High total parameter count remains demanding for local serving.
