## Decision checks before selecting M3

- Confirm the task benefits from image or video understanding rather than text-only response.
- Check whether the workload needs adaptive reasoning or a simpler response mode.
- Compare hosted API and local deployment using total operating cost.
- Inspect the actual weight license before recommending commercial self-hosting.
- Use repository deployment guidance to verify a supported inference engine.
- Plan memory for the full checkpoint; do not use activated parameters as the GPU estimate.
- Check regional eligibility, price thresholds and priority conditions for API traffic.
- Test long-context retrieval instead of relying on the 1M headline.
- Validate tool use and structured output on the exact service configuration.
- Do not treat MiniMax repository stars as deployment counts.
- Recheck lifecycle before selecting any additional M-series product.
- Keep provider benchmark claims attributed to MiniMax.

## Claims to keep bounded

- Open weights does not establish a particular commercial license.
- An official GitHub repo does not equal published model-weight terms.
- Activated parameter counts do not state total memory needs.
- Hosted token pricing and self-hosted operating costs use different denominators.
- A large context does not prove accurate recall over a long corpus.
- Product availability is not quantitative adoption evidence.
- Company-reported speed comparisons need attribution and workload context.
- Multimodal understanding does not guarantee all file types are accepted.
- Unknown license should remain a blocker to making rights assurances.
- Plan access and API access may have different terms.

## Review checklist for a recommendation

- Identify exact M3 model and hosting route.
- Confirm image/video need and reasoning mode expectations.
- Check hosted price conditions or local infrastructure costs.
- Keep weight license labeled unknown until verified.
- Check serving engine, memory and concurrency on target hardware.
- Test long-context and agent workflows with real examples.
- Attribute repository counters and benchmark comparisons.
- Recheck current model and deployment docs.
